# Smart Cache for Joomla: releases

Release packages of **Smart Cache for Joomla**, a page cache and speed extension for Joomla 4.4, 5 and 6 (PHP 8.1+), made by ThemeXpert. More at https://speed.themexpert.com.

- **Install:** download `pkg_smartcache-X.Y.Z.zip` from the latest [release](../../releases/latest), then in Joomla go to System → Install → Extensions and upload it.
- **Updates:** installed sites get new versions automatically under System → Update → Extensions (update feed: https://speed.themexpert.com/updates/joomla.xml).
- **Changes:** see [CHANGELOG.md](CHANGELOG.md).

This repository only holds release packages; it is not where development happens.
